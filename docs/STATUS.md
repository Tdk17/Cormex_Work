# Estado técnico

A branch de desenvolvimento implementa a jornada autenticada do cliente, seleção de UF/cidade pelo IBGE, reserva com recurso, visualização de endereço e horário local, ordem de serviço de oficina com orçamento e decisão do cliente, notificações internas e lançamentos financeiros manuais do proprietário. A API correspondente está no PR do BancoWorckk. O Flutter analyze e o build Web/PWA passaram no CI da branch.

Ainda faltam: implantação e teste real do Cloud Code no Back4App, Redis operacional, CLP/índices, documentos jurídicos e planos comerciais reais; geolocalização automática por dispositivo com consentimento e geocodificação, pacotes comerciais, fotos/histórico detalhado da OS, estornos, push e e-mail. Não declarar cadastro e operações funcionando em produção até concluir a validação integrada.
